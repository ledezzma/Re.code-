Preparar el entorno virtual: 
1. Crear carpeta general para la aplicación api (en nuestro caso la llamamos api)
2. Crear entrno virtual "dev" con: python -m venv dev
3. Desde la carpeta general ejecutar: .\dev\Scripts\activate para activar el entorno
4. Crear el archivo requirements.txt en la carpeta general con las dependecias que se usarán (en nuextro caso fastapi==0.142.2 y uvicorn== 0.54.0)
5. Instalar las dependencias necesarias mediante: pip install -r requirements.txt
6. Para salir del entorno virtual se introduce el comando: deactivate
