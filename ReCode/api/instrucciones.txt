Preparar el entorno virtual: 
1. Crear carpeta general para la aplicación api (en nuestro caso la llamamos api)
2. Crear entrno virtual "dev" con: python -m venv dev
3. Desde la carpeta general ejecutar: .\dev\Scripts\activate para activar el entorno
4. Crear el archivo requirements.txt en la carpeta general con las dependecias que se usarán
5. Instalar las dependencias necesarias mediante: pip install -r requirements.txt
6. Para correr el archivo se usa el comando: fastapi dev app.py
7. Para salir del entorno virtual se introduce el comando: deactivate

Pasos para hacer funcionar la app de Expo:
1. Desde la carpeta general "api" ejecutar: .\dev\Scripts\activate para activar el entorno
